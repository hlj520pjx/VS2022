## C# 扩展



### 封箱、开箱

#### 回顾值类型、引用类型

##### 值类型

存储在**栈内存**，变量直接存数据本身。

常见：`int`、`double`、`bool`、`char`、`struct`、`enum`

```C#
int a = 100; // a变量里直接放数字100
```

##### 引用类型

存储在**堆内存**，栈上变量存的是**地址**，指向堆里面的数据。

常见：`string`、`object`、`数组`、`list`、`字典`

> 注意：`object` 是所有类型的 “祖宗类型”，**任何数据都可以赋值给 object 变量**。

```C#
List<object> ls= [1,2,3,"dsfs",true]
```





#### 封箱

> 值类型 => object (引用类型)
>
> > 把栈上的值类型数据，打包放到堆里，拿到地址交给 object 变量。

```C#
// 装箱
int num = 20;      // num是值类型，栈内存存20
object obj = num;  // 装箱：把num的值复制一份，放到堆内存，obj存堆的地址
```

**封箱过程**

1. 在**堆内存**开辟一块新空间
2. 把 `num` 的值 `20` 复制进去
3. `obj` 这个引用变量保存堆那块内存的地址
4. 栈上原来的 `num` 不受影响，还是 20

> 注意： 不是把 num 搬过去，是**复制一份副本到堆**。修改原来 num，obj 里面的值不会变。

```C#
int num = 20;
object obj = num;
num = 99;
Console.WriteLine(num);   //99
Console.WriteLine(obj);   //20  副本互不干扰！

object o1 = 123;   //自动装箱
```



#### 开箱

> object => 值类型
>
> > 把堆里 object 包裹的数据，取出来，复制回栈上的值类型变量。
> >
> > > 拆箱必须强制类型转换！不会自动拆箱！

```C#
object obj = 20;        //装箱
int num2 = (int)obj;    //拆箱，强制转换
```

**开箱过程**

1. 检查 obj 堆里面存放的数据，是不是真的是 int 类型
2. 如果类型匹配，把值复制一份，给到栈上 `num2`
3. 如果类型不匹配 ===> 运行时报错 `InvalidCastException`

```C#
object obj1 = 20;
int num2 = obj1; //报错！ 不会自动拆箱

object obj2 = 40;
double d = (double)obj2; //报错！堆里装的是int，不能直接拆成double
```

> > 在开发中，要尽量少用装箱和拆箱,
> >
> > 因为频繁封箱和开箱是计算成本极高的操作，会消耗大量内存并严重拖慢程序的执行性能



### partial class

> 分部类
>
> C# 支持将一个类的定义拆分到多个文件中，使用 `partial` 关键字来标记类。
>
> 即**把同一个类的代码，拆分写到多个 .cs 文件里**，编译时编译器自动把它们合并成**一个完整类**。

#### 语法格式

```C#
// Student1.cs
partial class Student
{
    public int Id { get; set; }
    public void ShowId()
    {
        Console.WriteLine($"学号：{Id}");
    }
}
// Student2.cs
partial class Student
{
    public string Name { get; set; }
    public void ShowName()
    {
        Console.WriteLine($"姓名：{Name}");
    }
}
// Program.cs  调用
Student stu = new Student();
stu.Id = 1001;
stu.Name = "张三";
stu.ShowId();
stu.ShowName();
```

#### 分部类规则

1. 所有分部类必须同命名空间、同一个类名
2. 每一部分都必须加 partial，少一个报错
3. 访问修饰符必须统一 
4. 不能有重复成员
5. 两个文件里不能写一模一样的方法、属性，会有编译冲突
