简答题1： 

数组：适用于元素个数少且有固定长度的同种数据集合，可以直观地看到数组里面的元素的值，多用于少量的数据处理。优点是可以直观看到数据，缺点是数组中的数据一旦定好就无法修改。

List集合:数组的进阶版，具有数组的一些好的特性。对比数组来说list集合可以动态储存数据，通过list普通方法和高级方法可以改变list的长度和数据以及进行一些处理，这都是数组做不到的。

Dictionary<TKey, TValue>数据字典：字典可以储存多个含有不同类型元素的集合，可以通过字典方法对里面的数据进行修改。它适合储存多种被定义的数据。



简答题2： 
封装：把一些需要重复使用的代码给包裹起来做成一个函数，在需要调用的时候直接调用函数名（）就可以快速地使用。然后就是通过Class关键字可以把这些
具有某种关系的函数包裹成一个类，这个类里面可以另外定义一些属性和方法，以便我们可以在主函数那里快速地使用。

继承：如果A类想快速使用B类的方法不需要和B类一样定义相同的方法，直接让A类继承B类就可以，class A：B{ }就可以让A类调用和B类一样的方法，继承的A类叫做子类，被继承的B类叫父类。

多态:这里有两个写法：重写是子类在继承的基础上另外做的处理，子类可以通过override来重写父类的方法；重载是对类传入不同数量不同种类的参数来选择调用哪一种方法。

简答题3： 
JSON序列化：把数组、list列表和字典类型的数据转变成字符串，这样才能将信息写入文本中。
JSON反序列化：将读取到的字符串数据转变成相应类型的数据，方便进行后续的处理。

实现对象序列化的核心代码：
JsonSerializerOptions JsonOpt { get; } = new JsonSerializerOptions
        {
            WriteIndented = true,
            AllowTrailingCommas = true,
            Encoder = System.Text.Encodings.Web.JavaScriptEncoder.UnsafeRelaxedJsonEscaping,
        };
 string res=JsonSerializer.Serialize(序列化的对象,this.JsonOpt);
