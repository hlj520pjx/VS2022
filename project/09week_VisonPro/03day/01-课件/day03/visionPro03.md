# visionPro03

## 一、上节回顾

### 卡尺工具

> 查找测量边缘, 可以通过边缘的查找完成,尺寸的测量

- 卡尺方向: 测量方向,投影方向
- 对比度阈值/过滤一半像素/测量距离/查找数量/极性

### 定位工具

> 接受一个2D转换关系,创建一个定位坐标系;  

- 得到一个新的坐标系,可以给其他工具使用
- 输出一个像素尺寸不变的带 坐标系的图片

> 接受参数(2D转换关系),可以设置新坐标系名称,给其他工具选择使用
>
> > 一般可以PMA配合使用

- 灰度图转换
- PMA模板匹配
- 定位转换(创建新坐标系)

### 查找、拟合工具

- 找圆/线/拐角点/椭圆
- 拟合圆/线/椭圆

### 几何图形创建工具

- 文本标签
  - 一般都是用于标注(检测结果)
  - 可以接收多种类型结果
  - `{D:F2}`保留小数位/`{I:X}` 转进制/`{I:C}`货币/`{D:P2}`百分比/{B}布尔值
- 线: 点,角度
- 圆: 圆心,半径

## 四、基础脚本

我们在检测羊角工具，左边右边是否合格的时候，我们只能在图片上输出找到圆的个数或者卡尺使用到的个数，或者在图像上展示一些固定的数据，没有办法通过条件判断，得到我们想要展示的结果。

例如：手机电池标记正面反面字样，只能通过是否匹配到的数量得到结果。

如果要更加灵活的输出结果，需要写脚本。

写简单脚本需要使用BlockTool这个工具。

添加输出，在block工具上鼠标右击，选择Add Output，指定要输出的结果数据类型。

### 1、脚本使用

例：羊角工具是否合格，合格输出OK，不合格就输出NG

脚本需要打开Block工具，去写：

![1788333660062](assets/1788333660062.png) 

写代码的位置：

![1788333756943](assets/1788333756943.png) 

我们现在在block工具中写脚本，那么block工具中有的数据在代码中直接就可以获取到，例如：

要获取输入数据：`Inputs.Count`，要设置输出数据：`Ouputs.ConvertString`

例如：

```c#
public override bool GroupRun(ref string message, ref CogToolResultConstants result)
  {
    // To let the execution stop in this script when a debugger is attached, uncomment the following lines.
    // #if DEBUG
    // if (System.Diagnostics.Debugger.IsAttached) System.Diagnostics.Debugger.Break();
    // #endif
    // 判断
    if (Inputs.Count == 4) { // 输入的变量跟4比较
      // 输出：给输出的变量复制
      Outputs.ConvertString = "OK";
    } else {
      Outputs.ConvertString = "NG";
    }
    
    return false;
  }
```

写好代码后，生成发行，关闭窗口即可。

### 2、胶路检测案例

思路：使用多卡尺，判断卡尺数量是否用到的点的数量 跟 卡尺总数量是否相等；判断卡尺卡到的边缘对宽度是否大于或小于正常的宽度。

![1788338061769](assets/1788338061769.png) 

- 找线工具卡尺结果分析

![1789546912949](assets/1789546912949.png)

脚本：

```c#
public override bool GroupRun(ref string message, ref CogToolResultConstants result)
  {
    // To let the execution stop in this script when a debugger is attached, uncomment the following lines.
    // #if DEBUG
    // if (System.Diagnostics.Debugger.IsAttached) System.Diagnostics.Debugger.Break();
    // #endif

    // 定义结果字符串
    string text = "";
    // 定义开关
    bool flag = true;
    // 遍历
    foreach(CogFindLineResult item in Inputs.Results) {
      // 每个item是否断胶
      if (!item.Used) {
        text = "断胶";
        flag = false;
        break;
      }
      // 每个item是否溢胶
      if (item.CaliperResults[0].Width > 17) {
        text = "溢胶";
        flag = false;
        break;
      }
      // 每个item是否缺胶
      if (item.CaliperResults[0].Width < 15) {
        text = "缺胶";
        flag = false;
        break;
      }
    }
    // 判断是否ok
    if (flag) {
      text = "OK";
    }
    // 给输出赋值
    Outputs.Text = text;
    return false;
  }
```
